<objective>
Extend WaveManager's SpawnGroup config with SIX new optional fields — per-group `spawn_at` (time), `stagger` (time-drip within group), `position_mode` (exact/random distance), `angle_mode` (full/arc) + `angle_center`/`angle_width`, `cluster_radius` (drop-pod cluster), and `initial_state` (per-group AI state on spawn) — and update the perf-test wave (waves[0], `Performance test 2`) to exercise all of them on a single visually-layered wave. All existing waves[1..20] must continue to behave identically.

Purpose: Today every group in a wave spawns simultaneously at one fixed circle, with each enemy starting in IDLING. The user wants control over WHEN groups appear (spawn_at), HOW they appear over time (stagger), WHERE on the circle (angle_mode arc), HOW SPREAD around that point (cluster_radius), HOW FAR (position_mode random/exact + distance), and IN WHAT AI STATE (initial_state) — so wave authoring can express drop-pods, arc-flanks, dripped reinforcements, and pre-engaged snipers without code changes.

Output: A revised `components/wave-manager.gd` that accepts the new optional group fields with backward-compatible defaults, plus a revised `Performance test 2` wave entry in `world.gd` that demonstrates all six axes.
</objective>
