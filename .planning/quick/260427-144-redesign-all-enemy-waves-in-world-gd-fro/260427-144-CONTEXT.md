# Quick Task 260427-144: Redesign all enemy waves in world.gd - Context

<domain>
## Task Boundary

Redesign the entire `$WaveManager.waves` array in `world.gd`. Replace every existing wave entry (including the current `Performance test 2` wave at index 0) with a fresh, graduating set of themed waves that exercises every new SpawnGroup option from quick task 260426-r2b.

**In scope:**
- `world.gd` — replace the `$WaveManager.waves = [...]` block in full
- All new SpawnGroup options must appear across the campaign (every option used at least 2-3 times across the 20 waves so coverage is real, not token):
  - `spawn_at` (per-group time delay)
  - `stagger` (per-enemy drip within a group)

- Changes to `components/wave-manager.gd` (the schema is locked from 260426-r2b)

<decisions>
## Implementation Decisions

### Wave count + perf-test fate
- **Drop the perf-test wave entirely.** Replace `Performance test 2` (current wave 0) with the first themed gameplay wave.
- **Total: 20 themed waves.** No filler, no perf-test entry.
- If a perf test is needed later, it can be re-added as a separate console toggle or developer-only entry (out of scope here).

### Naming theme
- **Cosmic / astronomical.** Each wave gets a name evoking a celestial phenomenon at increasing scale (small → vast → catastrophic). Examples to draw from: Pulsar, Nebula, Solar Wind, Comet Trail, Asteroid Belt, Magnetar, Neutron Star, Black Hole, Quasar, Singularity, Event Horizon, Supernova, Hypernova, Heat Death.
- Names should suggest difficulty by their cosmic scale — `Pulsar` (early, rhythmic) reads as smaller than `Heat Death` (finale).
- Avoid mixing themes (no military codenames, no mythological — pick lane and stay).

### Difficulty curve shape
- **Escalating peaks with breather interludes.** Pattern: ramp up for 3-4 waves, drop intensity for 1 (the "breather"), ramp higher for the next 3-4, drop again, etc. Final 2-3 waves are the highest peak with no breather.
- Concrete shape across 20 waves (intensity scale 1-10):
  - Waves 1-3: 1-2-3 (intro ramp)
  - Wave 4: 2 (first breather)
  - Waves 5-8: 4-5-6-5 (mid ramp + mini breather)
  - Wave 9: 3 (deeper breather)
  - Waves 10-13: 5-6-7-6 (upper ramp + mini breather)
  - Wave 14: 4 (final breather before climb)
  - Waves 15-18: 6-7-8-7 (pre-finale ramp)
  - Waves 19-20: 9-10 (climax — no breather)
- "Intensity" combines: total enemy count, mix of high-threat types (Sniper, Suicider), use of `initial_state: "FIGHTING"` (no warm-up), and arc/cluster spawns that limit player escape angles.

### Per-wave option-coverage targets (so the 6 new SpawnGroup options actually appear)
Each option must be used in at least **2-3** distinct waves across the 20-wave campaign. Suggested distribution (planner can tune):
- `spawn_at` (multi-stage waves): used in ~70% of waves (most non-intro waves)
- `stagger`: ~6 waves (typically the "drip-in" feel for big swarms)
- `position_mode: "random"`: ~5 waves (chaotic / fog-of-war waves)
- `position_mode: "exact"` with explicit distance: ~5 waves (precise set-pieces)
- `angle_mode: "arc"`: ~6 waves (directional ambushes — north arc, east arc, etc.)
- `cluster_radius`: ~4 waves (drop-pod feel — Suiciders or Swarmers landing as a pack)
- `initial_state: "FIGHTING"` (or `"SEEKING"`): ~4 waves, mostly mid-late, to escalate without needing more enemies

### Claude's Discretion
- Per-wave enemy mix and exact counts (planner picks based on the intensity curve).
- Specific cosmic names mapped to each wave (planner picks; user reviews in plan approval).
- Exact `spawn_at` / `stagger` / `distance` / `angle_*` values per group (planner picks; tuning is part of the human in-game checkpoint).
- Whether to escalate enemy `speed_tier` per wave (existing field, not a new one — fine to use, but secondary to the new options).
- The breather waves can use ONLY one or two of the new options (they're breathers — simplicity is correct).
- Whether the finale (wave 20) also exercises one new option creatively (e.g. a Suicider cluster + initial_state FIGHTING + arc spawn from behind player heading) — yes, please make it the climax.

</decisions>
